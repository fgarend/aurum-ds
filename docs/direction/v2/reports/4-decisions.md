# Aurum under the new line: decisions, checks, roadmap and the app

Read on 2026-11-04, at `aurum-ds` commit `4d5b60d` (v0.3.0) and `wealth` commit `f489bb0`. Both repositories were only read.
`docs/direction.md` and `docs/direction/` are untracked in `aurum-ds`, and `docs/direction.md` is treated as a proposal.

**The line, as given by the owner:** shadcn is the base of the Aurum repository. Colours, spacing and fonts migrate to shadcn's
token and theme pattern. Components may change name and construction. Start from how shadcn does it, think whether to adapt,
and only if not, add our own.

**Marks:** **[M]** measured here, **[V]** verified with file and line or source, **[R]** reasoning, which can be wrong.

**How the measures were made [M]:** 16 `aria-nova` files, 1,495 lines, written by the shadcn CLI in the earlier trial
(`scratchpad/direction/trial/src/components/ui`). They were checked with Aurum's own `tsconfig.json` and `biome.jsonc`, with only
Biome's git link off, on TypeScript 7.0.2, Biome 2.6.3 and `react-aria-components` 1.22.1 from the image `aurum-web:test`. Logs are in
`scratchpad/direction-v2/4-measure/`. Storybook and `make check` were **not** run under Tailwind by this report (see "What could not be checked").

**Headline findings**

1. **All 90 records were read (0001 to 0090; `ls` shows 91 files with the README) [M].** 53 hold, 17 hold with a change, 9 fall, 11 must be re-decided by the owner [M, counted from section 1's table].
2. **Foundations and pipeline survive; the styling layer falls.** Containers, CI, releases, the package, axe, stories in three browsers and the update tools are untouched. The 406 lines of component CSS, the prefix and the token compiler go [R].
3. **Three checks pass while seeing nothing, and one fails falsely, in a Tailwind world [V].** Text spacing and most of forced colours select `au-` classes, so they would stay green on any Tailwind component. `css-tokens` reads only `.css`. Its breakpoint test fails once no `@media` is left. This is the largest risk for "Accessibility in the open".
4. **`make pack` fails on React Aria's own declarations [M].** Its settings (`exactOptionalPropertyTypes` on, `skipLibCheck` off) give 6 `TS2320` errors from `export * from "react-aria-components"`, and 0 without the flag.
5. **shadcn's focus ring fails Aurum's own bar [M].** `ring-ring/50` with Aurum's ring colour is 2.94:1 on `surface`, against 3:1. No current check sees it.
6. **The token collision has a cheap answer [R].** Aurum can take `:root`, and the app's v1 can move to `:root:not([data-ui="v2"])`, a selector it already uses for dark (`index.css`). `data-ui` sits on `<html>` (`uiVersion.ts:39`), so React Aria's portals inherit it too.
7. **The app's guard refuses the new line on its first step [V].** `index.css.test.ts:121` asserts the CSS does not contain `@fgarend/aurum-ds`, and Tailwind's `@source` and theme import need exactly that.

**Convention [V, `docs/decisions/README.md:10-15`]:** "Accepted decisions are never edited. When a decision changes, a new one replaces it. The old one
only gets its status changed to `Superseded by NNNN`". In part: "A decision replaced in part keeps its status, with what was replaced after it".
So nothing below is edited in place. Each change is a new record from 0091, written in the commit that first depends on it (0001), one decision per file,
with plain CSS and the rest kept as alternatives. Placeholders for those records follow the table.
