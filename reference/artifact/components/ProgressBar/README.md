# ProgressBar

A determinate progress indicator for goals, imports and limits.

**Props** — `value` · `max` (default 100) · `label` · `showValue` (shows the percentage, or `valueText` if given) · `tone`: `primary` (default) | `income` | `expense` | `warning` | `invest` · `size`: `md` (8px) | `sm` (4px).

**Use** — Savings goals in `income`, generic progress in `primary`. For spending against a limit use BudgetBar, which picks the tone for you.
