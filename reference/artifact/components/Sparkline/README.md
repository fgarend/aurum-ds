# Sparkline

A tiny trend line with a soft area and an end dot — no axes, no labels.

**Props** — `data` (≥2 numbers) · `width` (120) · `height` (36) · `tone`: default `primary` | `income` | `expense` | `invest` · `area` (default true) · `label` (set it to describe the trend when it stands alone).

**Use** — Beside a number (StatCard, account rows) to show direction. For real analysis use a full chart with the `chart-*` palette.
