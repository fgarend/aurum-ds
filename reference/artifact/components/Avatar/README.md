# Avatar

A person's photo or initials in a circle.

**Props** — `name` (required: initials and accessible name) · `src` (optional photo) · `size`: `xs` 20 (markers, switches) | `sm` 28 | `md` 36 | `lg` 48 · `tone`: 1–8, a person colour from the category palette (`cat-n` on `cat-n-soft`) — give each person one tone and keep it everywhere.

**Use** — Profile in the header or sidebar footer, shared-account members. Initials use `primary` on `primary-soft`.
