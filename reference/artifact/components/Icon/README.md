# Icon

The built-in line-icon set: 24px grid, 1.5px stroke, round caps and joins, drawn with `currentColor` so it takes the surrounding text colour.

**Props** — `name` (see `Aurum.Icon.names`) · `size` (px, default 20) · `strokeWidth` (default 1.5) · `label`: set it only when the icon stands alone and carries meaning; otherwise it is hidden from assistive tech.

**Use** — 16px inside small controls and badges, 18–20px in inputs, rows and buttons, 22px in BottomNav. Colour the icon through `color` (`ink-muted` by default in rows, the kind colour inside tiles). Never fill icons or mix in another icon family.
