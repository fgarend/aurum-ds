# Badge

A short status or category label on a pill.

**Props** — `tone`: `neutral` (default) | `primary` | `income` | `expense` | `invest` | `warning` | `outline` · `dot` (leading dot) · `icon` · `children` (one or two words).

**Use** — Status (“Pending”, “Paid”, “Overdue”), account type, asset class. Tone always matches meaning; a status also carries its word, never colour alone.
